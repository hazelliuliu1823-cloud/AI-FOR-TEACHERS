# 十四课时培训安排

来源：书稿 V1 附录G。

**表G-1　十四课时培训安排**

| 课时 | 主题 | 现场成果 |
| --- | --- | --- |
| 1 | 导言：人机协作的工作边界 | 用任务界定、证据组织、结果检验分析一项教师工作。 |
| 2 | 把真实任务说清楚 | 用最小充分信息完成一项真实Task说明，并确认专业任务必须守住的主线。 |
| 3 | 上下文与证据组织 | 信息身份、范围、冲突与最小证据包；练习“证据最多支持到哪一层结论”。 |
| 4 | 结果检验（Eval） | 四层结果检验 + 实施推演/失败路径 + 持续任务的触发与过程检查。 |
| 5—6 | 教学设计与备课 | 以材料研究课程为例，完成“上位任务确认→AI生成V0→五类偏差诊断→定向修正→实施推演”，形成可用的导入方案、教师手册和学生记录材料。 |
| 7—8 | 学生评价与学情诊断 | “观察—解释—行动”反馈和班级诊断证据链。 |
| 9—10 | 家校沟通与行政文稿 | 家长端、校内确认清单和发布审核。 |
| 11 | 从教学问题到研究课题 | 练习两条找题路径：从日常教学问题往上连接教育议题，或从较大方向往下收窄到真实课堂问题；完成候选问题比较和一页式研究设计。 |
| 12 | 合规、隐私与伦理 | 风险分级、数据最小化和责任审核。 |
| 13 | 从经验到可复用工作能力 | 区分Task、Project、全局规则、Skill、supporting files、scripts、Tool/MCP与Eval；形成一个Skill初稿并做baseline + 触发/过程/成果Eval。 |
| 14 | 持续任务与Agent运行框架 | 用Project/Task/Checkpoint跑一遍多轮协作，理解Agent、Harness、Environment/Sandbox的分层，并完成选择性写回。 |

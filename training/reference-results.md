# 练习材料与参考判断

以下为依据书稿整理的参考判断，不是学员实际提交或模型运行记录。课堂成果可能有多种合理写法，重点核对依据与边界。

| 练习 | 使用材料 | 应保留的判断 |
|---|---|---|
| F.1 教学设计 | [完整课程案例](../examples/material-research-course.md)、教学设计指令与检查卡 | 实际学情与知识起点由使用者补充确认；保留连续课程导入位置、两种不同研究入口；性质证据与功能证据分开；课时与预实验条件未齐不宣布可实施 |
| F.2 学生评价 | [两轮作文材料及参考反馈](../examples/student-feedback.md) | 首轮不能从三个分数与少发言推断动力；补材料后提出具体修改与后续观察 |
| F.3 家校沟通 | [完整输入、预告和校内清单](../examples/home-school-notice.md) | 当前只能形成预告候选；未确认费用等进入校内；建议岗位不是已指定负责人 |
| F.4 教学研究 | [研究案例](../examples/teacher-research.md)、一页式研究设计 | 教师是研究主体；先诊断，再确认问题；不预写有效提升；问题、行动与新增证据对应 |
| F.5 多材料总结 | [S1—S4及初稿检查](../examples/evidence-summary.md) | 两种实验、无成果展示；现场反馈不扩大为所有人感受；改进是建议，学习增量无证据 |

## 课堂使用

先让学员独立指出已有证据与缺口，再使用指令形成候选成果。教师确认后做一次定向修改，最后保留成果、关键依据与下一步，不要求保存全部对话。

第13课时使用[附录E](../templates/E-capability-evaluation.md)判断承载方式；适合Skill时形成初稿并测试，不适合时说明理由。第14课时用[连续任务示例](../examples/continuous-project.md)练习暂停、续接与选择性写回。

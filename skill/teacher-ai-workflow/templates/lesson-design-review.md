# 教学设计验收卡（通用）

适用于各学科。由书稿 V1 第4章“教学设计专用验收卡”中的通用项整理，并补入第1—3章的检查要求；材料研究类课程再加用 material-research-review.md。

- [ ] 若本课属于连续课程，上位目标、当前位置、必须继承的内容和后续交付已经确认，或已标为待确认。
- [ ] 学科主线清楚：每个环节学生要作出的学科判断明确，通用活动流程没有替代学科内容。
- [ ] 知识在学生需要作出判断时进入，深度与取舍由教师确认。
- [ ] 每个环节写明学生应留下的作品、记录或其他学习证据，课末成果可以观察。
- [ ] 学习支架回应具体困难，没有先按标签固定分组。
- [ ] 课时、人数、器材、实验参数没有编造；未确认的实施条件已经标出。
- [ ] 时间安排依据真实课时和预实验；尚未验证的，没有写成可行结论。
- [ ] 任务单、记录表的字段顺序与实际操作一致，区分原始证据、解释和待验证假设。
- [ ] 已按真实条件推演正常路径，并检查关键失败后学生和教师还能怎样继续；课前推演没有写成课堂效果。
- [ ] AI 生成的 V0 经过偏差诊断和定向修正，而不是直接作为定稿。

# 教师研究课题形成验收卡

- [ ] 研究主体明确为教师自己的教学研究，研究对象和情境具体。
- [ ] 课题不是从“热点词 + 模式研究”直接生成，而是能回到真实教学工作。
- [ ] 若从大方向进入，已经落到自己的课程、班级、任务和可观察现象。
- [ ] 若从日常困惑进入，已经确认它不是一次偶发现象，并找到值得追踪的具体断点。
- [ ] 已有证据足以说明问题值得研究；证据不足时先做诊断性观察。
- [ ] 教师能够采取实际教学行动，并在行动后继续取得新证据。
- [ ] 候选问题经过比较和收窄，题目没有预设“有效提升”等结果。
- [ ] 问题、行动、证据、判断标准和研究边界能够对应。
- [ ] AI 负责整理、比较和起草，研究价值判断、事实采用和最终选题由教师确认。
- [ ] 一个班级、单元或课程的发现没有被直接推广成更大范围结论。

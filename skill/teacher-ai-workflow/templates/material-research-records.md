# 材料研究记录与问题卡

依据书稿 V1 4.6节整理的配套模板。操作方案、重复方式与参数由教师确认；先预操作或试填再用于课堂。

## 性质测量记录

| 样品编号与基底 | 处理方式 | 原始图像编号 | 滴液条件 | 拍摄与读数时刻 | 测量位置或独立重复编号 | 左接触角 | 右接触角 | 异常与备注 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

保留原图与原始读数；角度单位统一为度。记录左右读数并不自动等于两次独立重复。同一样品的多次观测也不自动等于多个独立样品。

## 功能表现记录

| 样品编号 | 目标功能 | 测试条件 | 指标与记录口径 | 原始记录编号 | 处理前表现 | 规定处理与处理后表现 | 未处理对照 | 异常 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

本案例以透明观察窗为任务时，在已确认的统一凝结条件下另记清晰度等功能表现，不用接触角数值代填功能结论。

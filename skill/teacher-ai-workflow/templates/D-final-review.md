# 附录D　正式成果综合审核表

使用或发布前检查

| 检查项 | 检查项 |
| --- | --- |
| □ 任务：成果回应了真正需要解决的问题。 | □ 证据：重要事实和判断能够回到材料。 |
| □ 可用性：时间、对象、资源、行动和责任现实可行。 | □ 表达：文种、受众、信息顺序和篇幅合适。 |
| □ 数据：只使用必要信息，权限和匿名化符合要求。 | □ 教育：不标签化学生，不越过证据作人格、心理和家庭判断。 |
| □ 来源与权利：政策、引用、图片和作品来源可以核验。 | □ 责任：正式使用稿和最终确认人明确。 |
| □ 证据边界：关键证据明确支持到哪一层结论，没有从“有依据”跳成过度解释。 | □ 执行推演：需要真实执行的成果已走过正常路径，并检查关键失败后的下一步。 |
| □ 层级：嵌套任务已经继承相关上位基线，没有在局部生成中无故重开上位决定。 | □ 定向修正：初稿问题已经定位，正确内容没有因整体重写被破坏。 |

来源：《教师 AI 实用工作法》V1，相应附录。

# 家校沟通与行政文稿

先判断当前可以形成什么成果，再组织表达。日期、地点、费用等关键条件未确认时，适合先做预告候选稿与校内确认清单。

## 准备什么

使用对象、希望读者完成的行动、当前阶段和有效材料。标明已确认、拟定、待确认、失效与内部使用的信息。岗位建议不等于学校已经指定的责任人。

## 选择当前成果

| 当前工作 | 材料与重点 |
|---|---|
| 家长预告 | 已确认主题、对象和组织方式；拟定安排保留限定；未确认字段留在校内 |
| 正式通知 | 有效确认的时间、地点、参加方式、家庭行动、截止时间及异常联系渠道 |
| 内部执行方案 | 流程、岗位、资源、风险和待落实条件 |
| 总结与汇报 | 采用实际记录，区分完成情况、观察、评价和后续建议 |

同一事项可以有多个信息出口。把方案改为通知、把预告改为总结时，需要重新选择事实和证据，不只是换语气。

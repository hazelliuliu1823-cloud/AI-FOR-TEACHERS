# 暂停 换对话或交接后继续工作

项目保存跨任务有效的背景；任务保存当前目标、材料和成果；对话承载当前协作。先保持这三件事清楚，不必为普通任务维护技术状态文件。

## 什么时候保存进展

任务要暂停、换对话、交接，或重要决定已经形成阶段性基线时，用[Checkpoint卡](../templates/H-checkpoint-and-reuse.md)记下目标、已完成、已确认决定、当前成果、待解决问题和下一步。

继续工作时带上该记录与必要材料。证据包说明当前凭什么判断，Checkpoint说明已经做到哪一步，二者可以互相引用。没有实际文件或材料支持的内容不能靠交接摘要补成事实。

## 任务结束后

本次场地、人数和异常留在当前任务。同一项目后续需要的背景，经确认后进入项目说明。跨任务方法先作候选，继续验证后才固化。

## 使用更强工具时

Skill提供任务方法，工具负责访问资料和执行动作，Agent围绕目标推进，Harness组织模型、工具和状态，执行环境承担文件与代码操作。Session和Checkpoint不同：前者是交互或运行实例，后者是恢复任务需要的进展记录。

这些概念不要求教师额外维护一套系统。操作方式可以变化，事实边界、已确认决定和最终责任仍需保留。

# 把任务说清 把证据用准 检查结果

一次构思可以从一句话开始。需要进入课堂、评价、正式通知或实际执行的成果，要补足目的、材料、边界和使用标准。

## 开始前

说明要做什么、给谁使用，附上与当前任务直接相关的材料。如果任务属于一个更大的课程或项目，再说明当前位置、必须继承的决定和下一阶段需要的成果。只追问会改变结论、行动或使用条件的信息。

## 材料较多时

先分清计划、已确认决定、实际发生、观察或评价、待确认。对有冲突的材料，按当前问题选择依据：安排看有效确认，完成情况看现场记录，学生表现看作品与过程，不能简单以最新日期覆盖全部旧材料。

每条重要结论要能说明依据支持到哪里。把当前可以采用、需要限定使用、暂不使用的内容整理成最小证据包，保留来源和必要条件。最小不等于删掉会改变判断的背景。

## 拿到初稿后

先看任务、事实、实际可用性，再看表达。复杂专业任务可以按任务、专业主线、层级、证据、实施五类定位偏差。把问题与保留项一起交给 AI，只改指定部分。

需要真正执行的方案，按实际顺序推演一次，再检查一个关键失败发生后还能怎样继续。达到使用标准后，由教师定稿。

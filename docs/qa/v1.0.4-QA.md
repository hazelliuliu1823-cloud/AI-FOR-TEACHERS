## 迁移与验证边界

从 v1.0.3 更新时，先补真实核听和采用引用，再按已确认决定更新 Direct 2 授权并重新编译，具体步骤见 [INSTALL.md](../../INSTALL.md)。只重算指纹不能替代实际核查。

本轮没有真实长视频。合成数据验证声明记录之间的机械关系；独立执行验证文档可用性；可控媒体验证审计兼容性。它们不证明实际观察质量、说话人准确率、最终听看、决策者身份或成本降幅。

继续保留原报告指出的职责边界：Broad 覆盖完成判定、逐帧唯一性 / 帧尾上界、4fps 实际执行、说话人和否定性事实的语义证明、time_mapping 有效类型未扩展；Deep 保护要求仍由 Direct 2 转移 / 裁决，音乐与环境声的整体收束仍需人工对账及最终核听。外部渲染器须接入入口检查，不能把绕过入口的任意渲染器描述为已受限制。

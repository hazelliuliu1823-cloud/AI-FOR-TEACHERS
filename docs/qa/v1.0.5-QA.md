## 实际改动

每条 source_id 音轨独立从实际取段及可选明确采用 ID 推导已知 utterance。卡片声音、未关联额外音轨和异源仅音频均检查来源、当前绑定、audio_verified 与整句 audio review；保留政策下还检查有效处理、增益、淡音及完整可听覆盖。视频关联用于既有同步检查，不再决定对白检查资格。

音轨独有 utterance 及其专属 review 纳入 adopted_evidence_digest。确认后改动这些记录，使旧确认失效；即使重新确认快照，过期或未核实证据仍会被正式编译拒绝。

已关联原声沿用 event 级保护、同步、原因和例外。独立声音按源时间、speed 与成片位置处理，允许异步放置；同源、同 speed、映射一致的有效轨可以跨卡片连续保留整句。独立删句使用 track 级 audio_required_range，明确改变保留政策使用 track.dialogue_policy_reason，不增加创意阶段。

## 迁移与验证边界

v1.0.4 项目保留 Structure 和全部正式表。独立源对白须对账整句证据、实际声音处理、成片位置和具体创作例外；完成后按已有创作授权更新 Direct 2 机器记录并重新编译，详见 [INSTALL.md](../../INSTALL.md)。只改指纹不能替代核听或裁决。

本轮没有真实长视频。合成记录验证可机械判断的数据关系，可控媒体验证审计接口；数量不是实际剪辑错误率、观察质量、最终观感或成本降幅。具体可听性、完整观察、说话人及最终听看仍须真实素材支持。

Broad 覆盖完成计算、逐帧唯一性 / 帧尾上界、4fps 实际执行、说话人与否定性事实的语义证明、time_mapping 有效类型均未扩展。Deep 保护向 unit / boundary 的转移仍由 Direct 2 裁决；纯音乐和环境声整体收束仍由人工对账与最终核听负责。外部渲染适配器须接入 guard，哈希不证明审阅者身份或真实听看。

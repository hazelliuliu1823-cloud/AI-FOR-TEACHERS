## 实际改动

1. 采用 evidence、review、unit verification、utterance、boundary、event 和源音轨增加当前 source / time-mapping 绑定，旧证据不能继续执行。
2. Direct 2 保存机器可读执行授权，核对事件、unit、boundary、顺序、音轨、文字、转场与允许调整，并绑定决策文件和采用证据的版本。
3. 对独立原声音轨核对完整对白 / 尾音、源与成片时长、同步、静音和淡音；J/L-cut 与创作截尾须有具体已确认依据。
4. 实际视频和音轨取段受到 source_scope、usable_ranges、allowed_scope 及 typed source constraints 限制；无关、失败或占位 review 不能放行 override。
5. 正式编译拒绝未就绪草稿，planning 清单明确不可渲染；新增渲染入口检查拒绝输入失效和清单改写。声音缓存补输出 fps 依赖。
6. README 首屏集中呈现低成本复用、丰富结构与人工创意，完整原技术说明保留在展开部分；新增安装说明、Release Notes、可运行测试与合成示例。

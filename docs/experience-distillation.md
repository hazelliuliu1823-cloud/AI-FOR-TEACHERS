# 判断哪些经验值得留下

先区分本次事实、项目长期背景与可能复用的方法。一次做成功不等于形成稳定能力，也可能只需要留下一张模板或一份参考资料。

| 留下的内容 | 合适位置 |
|---|---|
| 本次事实、临时决定、一次异常 | 当前任务 |
| 同一项目后续仍有效的确认背景 | 项目说明 |
| 跨任务共同遵守的原则 | 共同规则 |
| 一类任务反复有效的专业方法 | Skill候选，继续验证 |
| 较长知识、案例、量规、模板 | 参考文件或可复用资产 |
| 确定性操作 | 脚本或固定流程 |
| 实时数据与外部动作 | 工具或系统连接 |

先保留任务输入、偏差、教师纠偏及结果。只有换任务仍然有效，才逐步固化。还没有足够证据时，可以决定暂不沉淀。

验证能力时，比较普通要求下的输出与加载专用能力后的输出，检查触发、过程、成果；修改后再检查旧任务。记录模型和日期，模型已经自然完成的微步骤不必一直保留。

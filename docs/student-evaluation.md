# 学生评价与学情诊断

先确定反馈给谁、支持什么行动，再整理作品、结果与过程。一次低分或公开发言少，不能直接解释为动力不足、性格内向或家庭原因。

## 准备什么

匿名作品、题目要求、评分口径、订正稿和与任务有关的过程记录。比较成绩时还需对象、满分、难度与有效样本范围。已有材料只能支持有限反馈时，可以先提出具体行动，不必等待完整个人档案。

## 写给学生的反馈

先在心里分开观察、解释、行动，再写成自然文字。观察要能回到材料；解释保持有限且可修正；行动应能在下一次任务中完成，并说明用什么证据看变化。

## 做班级诊断

先核对比较口径，再从题目和匿名作答找可改变的断点。选择一个断点调整支架，用相近任务观察独立完成、提示后完成和仍未完成的情况，人数与有效总数对应。没有分母，不报告比例；没有可比条件，不直接声称能力下降。

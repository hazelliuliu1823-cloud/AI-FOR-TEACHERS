# 材料使用与正式成果的责任

把完成任务真正需要的材料交给 AI。匿名化不能只删姓名；具体班级、罕见经历、健康信息和照片背景组合后仍可能识别个人。

学生评价回到作品、数据与过程，不从有限行为推断性格、心理或家庭原因。处分、评优和重要机会分配等决定，由教师和学校责任人作出。

能够读写文件，不等于有权覆盖已确认成果、修改项目长期背景或对外发送。开始时说明允许的动作，涉及正式承诺和发布时确认责任人。

正式使用前用[综合审核表](../templates/D-final-review.md)检查任务、证据、可用性、表达、数据、教育影响、来源与责任。中高责任成果保留必要的材料来源、人工修改和最终审核记录。

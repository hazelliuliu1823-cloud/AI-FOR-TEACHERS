# 教师 AI 实用工作法

从“让 AI 回答”到“与 AI 完成工作”。面向一线教师的开源 AI 工作方法包，包含完整教材、教学设计、学生评价、家校沟通、教学研究指南，以及可直接使用的 Prompt、模板和案例。

这里提供教师可以直接使用的工作指南、指令、案例和模板。带上自己的真实材料，在平时使用的 AI 对话工具中就可以开始。

## 你想完成什么工作

| 工作 | 从这里开始 |
|---|---|
| 教学设计与备课 | [把课程要求转成可实施的课堂](docs/lesson-design.md) |
| 学生评价与学情诊断 | [从作品和记录形成反馈与教学调整](docs/student-evaluation.md) |
| 家校沟通与行政文稿 | [完成通知、方案、总结和汇报](docs/home-school-communication.md) |
| 教师教学研究 | [从教学问题形成研究设计](docs/research-topic-development.md) |

打开相应指南，准备必要材料，复制指令，再对照案例和检查卡核对结果。已有初稿时，可以直接从检查和局部修改开始；简单任务不必填写全部模板。

# 教师 AI 实用工作法

从课程构思、学生反馈到家校沟通和教学研究，让 AI 跟着教师的真实工作逐步推进。

从一个想法、一份作品或一段初稿开始，形成建议、方案与文稿，再核对依据和使用条件。

## 先看一次协作

老师想开一门跨学科课程，还没有选定主题。下面摘自已有三轮试答，展示从构思到课程框架的推进方式。

| 教师提问（节选） | AI 怎样推进（摘要） |
|---|---|
| “学校让我们开一门跨学科课程，我还没想好从哪里下手。” | 比较校园真实问题、身边事物的来历、动手解决问题三类方向，推荐从校园问题入手，并说明学科怎样衔接。 |
| “面向初一，想从校园生活出发，还没决定具体主题。” | 推荐“让教室更舒适”：科学负责测量，数学整理和比较数据，语文形成有依据的建议书。 |
| “具体课时和器材还没定，你先把整体课程框架和学生成果展开。” | 沿用该方向，展开阶段任务、学生成果与评价依据；课时、器材等实施条件保留待核实。 |

最后形成的学习推进线是：**发现问题 → 设计测量 → 取证 → 分析 → 改进尝试 → 建议与汇报**。学生成果包括测量方案、原始记录、图表与分析说明、改进前后对比、建议书和汇报。

[查看完整三轮问答](showcase/course-planning.md)。这是试答示例，课堂实施与学习效果尚无记录。

## 开始使用

### 复制指令试用

在平时使用的 AI 对话工具中复制下面的课程构思指令，也可以把最后一行换成你的任务：

```text
请与我协作完成一项教师工作，按我当前的请求深度展开。
根据当前信息先给有理由的建议、做法或草稿，再问最影响下一步的条件。
我补充信息后，承接已有讨论继续推进，区分已有事实、建议和待确认条件。
形成正式材料时，核对依据、实施条件和使用前需要确认的事项。

我现在想做的事：我想做一个跨学科课程，有什么建议？
```

这段指令用于先体验协作方式；进一步备课、写反馈、做沟通或教研，可以使用下方对应场景的完整指令、模板和案例。

### 安装 Skill

如果你使用的 AI 工具支持 Skill（Agent Skills），可以安装 [skill/teacher-ai-workflow](skill/teacher-ai-workflow/SKILL.md)。成功加载后，教学设计、学生评价、家校沟通和教学研究都可以从“有什么建议”“怎样做更好”等宽泛问题开始；AI 先给当前能支持的专业建议，再随条件补充推进，正式使用时仍需核对事实和责任边界。具体触发方式以所用工具为准。安装方法见 [INSTALL.md](INSTALL.md)。

Skill 只包含 AI 工作时需要的方法、模板和案例；书稿、培训安排和给教师复制的指令仍在本仓库的其他目录中。

# 暂停与续接任务指令

依据书稿 V1 第10章和附录H整理。

## 暂停前

```text
请依据当前任务中已经确认的信息整理一份简短Checkpoint：当前目标、已完成、已确认且不得无理由改变的决定、当前成果文件、未解决问题、下一步。
保留必要的材料编号和文件位置，引用当前证据包，不复制全部历史对话。将AI建议与教师已确认决定分开。没有完成的动作不能写成完成。
```

## 换对话后

```text
这是要继续的任务：【Checkpoint及必要材料】。
请先核对你实际能看到哪些材料，复述本轮目标、已确认决定和证据边界。不要继承其他任务的临时条件，不重新解释已经确认的要求。
从记录的下一步继续；材料缺失时，只说明影响继续工作的关键缺口，不自行恢复不存在的文件或事实。
```

## 结束时

```text
请整理本次任务新增的事实、决定与方法候选。逐项判断只留在Task、供当前Project后续使用、作为可复用能力候选，还是需要更多任务验证后才能考虑共同规则。
写明理由及验证依据。不确定时留在较低层级，一次成功不自动改写Skill。请提出写回建议，等待教师确认。
```

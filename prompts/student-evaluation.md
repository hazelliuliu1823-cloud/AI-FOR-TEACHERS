# 学生评价与学情诊断指令

依据书稿 V1 第5章整理。给 AI 的材料应只包含完成本次任务需要的信息。

## 个体反馈

```text
反馈给【学生/家长/教师】，用途是【用途】，观察时段为【时段】。
匿名材料：【作品、题目要求、评分说明、订正和相关过程记录】。
请先区分可观察表现、目前能作出的有限解释、下一步行动。解释注明依据，材料不足处写“当前无法判断”。分数缺少可比口径时，不据此判断能力或动力变化；不推断性格、心理、家庭原因及长期能力。
肯定行为时只用有记录的行为，不写泛泛标签。为下一次任务提出少量具体行动，并说明用什么新作品或过程记录检查效果。
最后按使用对象写成自然的反馈候选稿，不必保留OEA栏目形式，交由教师确认。
```

## 班级诊断

```text
需要解决的教学问题：【填写】。
材料：【测试对象、满分、难度与范围、题目维度、匿名作答、订正及过程记录】。
先核对比较口径和有效样本。缺失的人数、分母或得分背景不得自行补齐，不能把待核实线索写成精确变化。
从实际作答拆解条件提取、关系表达、步骤完整性等具体断点，仅使用适合当前学科任务的维度。把直接证据、候选解释、证据缺口和可调整的教学行动分开。
提出一个短周期调整及下一次观察方式，记录独立完成、提示后完成和仍未完成的情况。说明何时继续、撤除或更换支架；不要将成绩变化直接归因于态度或家庭管理。
```

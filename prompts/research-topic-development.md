# 教师教学研究指令

依据书稿 V1 第7章整理。只复制当前需要的一段，不要求所有任务按固定轮次执行。

## 找研究线索

```text
我的教学情境：【班级、课程、任务】。
现有匿名材料：【作品、课堂记录、问题卡、反馈等】。
我关注的教育方向（如有）：【填写】。
请先不要起课题名称。从材料中整理反复出现或值得继续观察的现象；如果我给了较大方向，再把它落到当前教学中可以观察的问题。分别列明事实、可能解释和证据缺口，不凭方向推定本班已经存在某个问题。
把现象拆到具体学习或教学环节，说明教师能调整什么、还需什么材料确认。证据不足时，提出一个短周期诊断性观察安排。
```

## 比较候选问题

```text
已确认的教学现象与依据：【填写】。可投入的周期与条件：【填写】。
请提出3—5个不同尺度的研究问题候选，先不写正式课题名称。逐项比较教学价值、证据基础、可干预性、可持续观察和范围适当性。
说明每个问题具体回答什么、需要哪些已有及新增证据、教师可以做什么、最容易越界的结论是什么。没有材料支持的部分保留待确认；不要替我最终选题。
```

## 形成一页式研究设计

```text
我已确认的研究问题：【填写】。有效材料与边界：【填写】。
请形成一页式研究设计，说明情境与对象、一个主问题及必要子问题、已有证据、教学行动、新增证据、判断标准与实施阶段、研究边界。
每项行动对应能够取得的证据。标准写成待观察的表现，不预写改善幅度或研究结果。现有材料不足时指出诊断阶段需要完成的取证。
在问题确认后提出与其一致的课题名称，避免把一个班级或一门课程的发现扩大到整个学段。
```

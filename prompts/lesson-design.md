# 教学设计指令

按任务选择使用。以下指令由书稿 V1 第4章方法整理，属于配套使用文本；材料研究案例的具体内容见[完整案例](../examples/material-research-course.md)。

## 确认课程位置与主线

```text
我要设计【当前课或单元】，课程要求与学生情况见【材料】。
请先不要生成完整教案。若这是连续课程的一部分，整理上位目标、本课位置、已经确认的继承项和课末需交给后续的成果；独立单课不额外增加上位分析。
请说明本次不能被通用活动流程替代的学科主线，学生应完成什么判断，并留下什么作品、记录或其他学习证据。缺少依据的条件列为待确认。
提出必要的不同设计路径及取舍，供我确认，不把你的推荐直接当作既定决定。
```

## 形成完整初稿

```text
以下是已确认内容：【目标、位置、主线、学习成果和知识支架】。
实际已知实施条件：【填写】。尚未确认：【填写】。
请形成【教案/课程方案/教师手册】初稿。每个环节写明学生面对的问题、实际任务、此时需要的知识或方法、应留下的证据及进入下一环节的条件。
学习支架应回应具体困难，不先按标签给学生固定分组。不要重开已确认的课程决定；不编造课时、人数、设备和实验参数。
材料研究任务应分别核对性质表征与功能评价，不能把一种指标代替另一类结论。其他学科则按本任务的证据关系判断，不强套材料研究链。
```

## 诊断与局部修订

```text
请对照已确认要求检查当前初稿，按任务、专业主线、层级、证据、实施五类指出具体偏差；没有问题的类别不必凑项。
先交付问题清单、依据与保留项，不整体重写。待我确认后，只修改指定问题，再逐项检查保留内容是否仍然成立。
```

## 配套学生材料与实施检查

```text
以已确认方案【文件】及真实操作条件【材料】为准，形成学生任务单、记录表和课末问题卡。
让字段顺序跟实际操作一致，区分原始证据、解释和待验证假设。每条数据应能回到原始记录；不要只留下最终平均值。
按真实时间、资源和工位推演准备到结束的过程。指出正常路径的具体断点，以及关键失败后可以继续的动作。实际参数不够时列明待核实条件。
把可以直接修正的字段或说明，与必须由教师做预实验、学生试填或课堂观察才能判断的问题分开。不要把课前推演写成已发生的课堂效果。
```

## 实施后复盘

```text
下面是匿名学生记录、退出题表现、实际耗时和教师观察：【材料】。
请只比较原定目标、实际证据与仍存在的困难。分别说明已实现部分、证据不足部分和下一次需要调整的具体环节，不推断学生态度、性格或长期能力。
指出哪些信息只属于本次课堂，哪些值得在后续任务中继续验证。不要因本次成功自动改写长期规则或Skill。
```

# 家校沟通与行政文稿指令

依据书稿 V1 第6章整理。起草与发布分别处理。

## 判断当前能写什么

```text
任务：【填写】。使用对象：【填写】。希望对方完成的行动：【填写】。
材料及其状态：【已确认、拟定、待确认、失效、内部使用】。
请先判断现在适合形成预告、校内确认清单、正式通知、执行方案还是总结。必要时分成多个成果，不强迫一篇文稿承担全部职责。
只将当前状态允许使用的信息写入对应成果。拟定事项保留限定，待确认事项进入内部清单，失效内容不沿用，内部岗位和风险讨论不直接放进家长文稿。
不得补造日期、地点、人数、费用、联系方式或承诺。责任人尚未指定时，可以提出岗位建议，但明确它只是建议。
```

## 起草与审核正式通知

```text
以下是已经获得有效确认的安排：【材料】。
请为【收件人】起草【通知】。先搭事实与行动骨架，再调整语气和篇幅：何时、何地、谁参加、怎样往返、读者要做什么、截止时间和渠道、异常情况联系谁。
成稿后单独核对事实来源、行动完整性、对外承诺授权、内部信息分流、审核人和发布渠道。缺少关键条件时标出不能正式发布的原因，不用常见做法补齐。
本次只形成候选稿，不代替责任人批准或实际发送。
```

## 总结 汇报或文种转换

```text
目标文种与用途：【总结/汇报/发言稿等】。对象与篇幅：【填写】。
当前有效材料：【实际记录、已确认安排、现场反馈等】。
先检查哪些内容适合当前文种和对象。筹备计划不能写成实际成果；没有作品、过程或测量依据，不写学生能力提高或育人成效显著。建议与已经落实的行动分开。
如果从另一文种转换，请指出需要替换的证据、应删的信息和仍须保留的行动字段，再形成候选稿。
```

# 任务 材料与结果检查指令

以下是依据书稿 V1 第1—3章整理的完整使用版本。替换方括号内容，只复制当前需要的一段。

## 开始一项任务

```text
我需要完成【成果】，给【对象】使用，目的是【目的】。
现有材料：【粘贴或附上材料】。
已确认条件和必须保留的决定：【填写】。
尚未确认、不能推断或不能改变的内容：【填写】。
达到以下标准就可以交付：【填写】。
请判断当前信息是否足够。只追问会明显改变结论、读者行动或正式使用条件的缺口，集中提出不超过3个关键问题。信息足够则直接开始；不要自行补事实。
如果这项任务嵌在更大课程或项目中，请先核对其目标、位置、继承项和后续交付。
```

## 整理多份材料

```text
当前任务：【填写】。材料：【粘贴并保留材料编号】。
请提取与任务直接相关的信息，保留来源位置和适用范围，分清计划、已确认决定、实际发生、观察或评价、待确认。
冲突与缺口分别列出。不要仅按文件时间决定采用哪一条，也不要把不同说法拼成新的事实。
整理为可以采用、审慎使用、暂不使用。对关键判断注明：证据支持什么，还不能支持什么。
保留本轮目标、必须继承的条件、排除项和来源，形成最小证据包。先复述这些边界，再根据当前可交付程度起草成果。
```

## 检查初稿

```text
任务和有效依据：【填写或引用当前已确认材料】。
待检查初稿：【粘贴】。
请先检查，不要重写。逐项看任务是否匹配，事实与判断是否有依据，现实中能否使用，表达格式是否合适。
复杂专业任务再判断偏差属于任务、专业主线、层级、证据还是实施问题。指出具体位置、依据和建议改法，同时列出已经正确、需要保留的内容。
如需实际执行，按准备、启动、执行、记录、异常处理到结束推演，指出具体断点；再检查关键失败后的下一步。缺少真实时间或资源数据时保留缺口，不编排出看似精确的可行结论。
```

## 按确认范围修改

```text
以【文件或本轮底稿】为准，只修改以下问题：【问题清单】。
以下内容已确认并须保留：【保留项】。
未列出的文字、数据、结构和其他内容保持不变。缺少依据处保留待确认，不补造。
修改后逐项说明实际改动，并检查保留项是否仍然成立。
```

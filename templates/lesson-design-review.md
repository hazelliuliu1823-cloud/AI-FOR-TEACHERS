# 教学设计专用验收卡

本卡保留书稿材料研究案例的检查项。用于其他课程时，将材料专用项目替换为本学科相应判断。

- [ ] 若本课属于连续课程，上位目标、当前位置、必须继承内容和后续交付已经确认。
- [ ] 学科知识沿材料问题进入，研究方法没有替代课程内容。
- [ ] 两类材料研究入口及课堂主线服务课程目的。
- [ ] 性质表征与目标功能验证已经区分，任务单和记录表能分别保存两类证据。
- [ ] 时间安排依据真实课时和预实验。
- [ ] 导入留下可进入选题的样品、数据、记录和开放问题。
- [ ] 两次导入共享基本研究方法，同时保留不同的材料问题与知识链。
- [ ] 实施前完成正常路径与关键失败路径推演，实施后再用真实证据校准方案。
- [ ] AI生成的V0已经经过偏差诊断和定向修正，而不是直接作为定稿。
- [ ] 实施前已用真实条件推演正常路径与关键失败路径。

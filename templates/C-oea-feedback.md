# 附录C　观察—解释—行动反馈卡（OEA）

这张卡用于教师在形成反馈前梳理证据、判断和行动。短任务可以先填写前三项；需要持续跟进时，再补充后续观察。

**表C-1　观察—解释—行动记录**

| 思考层次 | 记录内容 |
| --- | --- |
| 观察（Observation）：可以直接看到的作品、行为、数据或过程证据 |  |
| 解释（Explanation）：基于现有证据作出的有限、可修正判断 |  |
| 行动（Action）：学生或教师下一步可以完成的具体动作 |  |
| 后续观察：何时、用什么材料判断行动是否有效 |  |

来源：《教师 AI 实用工作法》V1，相应附录。
